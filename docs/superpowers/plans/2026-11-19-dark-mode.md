# MewBot Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambahkan mode gelap hangat ke dashboard MewBot lewat satu tombol di header, tanpa mengubah satu piksel pun tampilan terang.

**Architecture:** 81 warna yang sekarang ditulis langsung diangkat menjadi CSS variable di `globals.css`. Mode terang memakai nilai hex yang identik, mode gelap menimpa variable yang sama di bawah selektor `.dark`. Tailwind memetakan setiap variable ke kelas utilitas, sehingga halaman tidak lagi menulis warna. Tombol tema menukar kelas `dark` di `<html>` dan menyimpannya di `localStorage`; skrip inline di `<head>` memasang kelas itu sebelum halaman digambar agar tidak berkedip.

**Tech Stack:** Next.js 15 App Router, React 19, TypeScript, Tailwind CSS 3 (`darkMode: 'class'`). Tanpa dependensi baru.

**Spec:** `docs/superpowers/specs/2026-11-19-dark-mode-design.md`

## Global Constraints

- **Tampilan terang identik byte demi byte.** Setiap token terang memakai nilai hex persis seperti yang digantikan. Diverifikasi oleh tes, bukan ingatan.
- **Nol dependensi baru.** Jangan mengubah `dashboard/package.json`.
- **Nol font unduhan.**
- **Tidak mengubah** teks, tata letak, rute, API, payload, atau interval polling.
- **Tidak menyentuh** `firmware/**` atau `supabase/**`.
- **Pratinjau OLED dikecualikan.** `.oled-screen-preview` dan seluruh kelas `emerald-*` di dalam `/pesan` tetap literal di kedua mode.
- **Nilai token terang, verbatim:** `--bg-primary #fcfbf7`, `--bg-surface #ffffff`, `--bg-surface-subtle #f6f3eb`, `--bg-raised #ffffff`, `--border-subtle #eae4d5`, `--border-chip #cbdbca`, `--text-main #1e241f`, `--text-muted #5e6b5f`, `--text-dim #8b998c`, `--text-on-dark #ffffff`, `--olive-primary #466743`, `--olive-hover #385336`, `--olive-subtle #eef4ea`, `--olive-deep #273826`, `--olive-accent #5a8257`, `--on-olive #ffffff`, `--on-danger #ffffff`.
- **Nilai token gelap, verbatim:** `--bg-primary #16140F`, `--bg-surface #201D17`, `--bg-surface-subtle #2A2620`, `--bg-raised #2E2921`, `--border-subtle #332E26`, `--border-chip #3C4A38`, `--text-main #EFEAE0`, `--text-muted #A8A092`, `--text-dim #928A7B`, `--olive-primary #8FB08A`, `--olive-hover #A3C29E`, `--olive-subtle #2A3527`, `--olive-deep #D6E3D2`, `--olive-accent #9BBE96`, `--on-olive #16140F`, `--on-danger #16140F`.
- **Palet status, terang = nilai Tailwind asli, gelap = nilai terukur.** Tabel lengkap ada di Task 2.
- **Target sentuh tombol tema ≥44px.**
- **Tanpa kedipan.** Kelas `dark` harus terpasang sebelum paint pertama.

## Review Focus

Hal yang spec minta tetapi tidak diuji langsung oleh asersi, dan paling mungkin merusak pengalaman pemakai:

1. **Tampilan terang berubah tanpa sengaja** saat 703 penggantian warna berjalan. Asersi: Task 10 membandingkan tangkapan layar mode terang sebelum vs sesudah, harus nol perbedaan piksel.
2. **Kedipan putih saat memuat dalam mode gelap** — pengguna melihat halaman terang sekejap lalu gelap. Asersi: Task 4 memeriksa bahwa skrip tema ada di `<head>` sebelum `<body>`, dan Task 10 memeriksa `document.documentElement.classList` pada muat pertama.
3. **Pratinjau OLED ikut berubah warna** sehingga simulasi perangkat jadi bohong. Asersi: Task 8 menolak tokenisasi di dalam `.oled-screen-preview`.
4. **Teks tidak terbaca di latar gelap** pada pasangan yang tidak diukur di spec (chip status, tombol destruktif). Asersi: Task 2 mengukur 59 pasangan palet + 15 pasangan permukaan.
5. **Item terpilih di atas track terlihat tenggelam** karena `--bg-surface` lebih gelap dari `--bg-surface-subtle` di mode gelap. Asersi: Task 9 memeriksa segmented control punya pembeda selain warna.
6. **Pilihan tema hilang saat refresh atau antar-tab.** Asersi: Task 4 menguji `localStorage` dan event `storage`.
